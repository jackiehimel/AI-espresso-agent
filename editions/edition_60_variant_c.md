## NVIDIA just shipped a reasoning model built for self-driving cars

Alpamayo 2 Super is designed to handle the rare, complex driving situations that break conventional object detection—like figuring out why a cyclist is swerving or what to do when construction cones appear mid-lane. It's now available for commercial use in robotaxis and autonomous vehicles.

*Self-driving still fails on edge cases; this targets exactly that gap with situational reasoning.*

## Meta just open-sourced two new coding models that run locally

Muse Code handles everyday programming tasks, while Muse Spark 1.2 is a tiny model designed to run on your laptop or phone without a GPU. Both are Apache 2.0 licensed. Meta says Spark beats other small models on coding benchmarks while using a fraction of the parameters.

*You can now run a decent coding assistant entirely offline on consumer hardware.*
