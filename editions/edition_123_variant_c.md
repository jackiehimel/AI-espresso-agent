## Opera just let you run AI models directly in your browser

Opera's new WebAI standard lets you run open-weight models like Gemma locally in the browser—no cloud, no subscription, no sending data to servers. *First browser standard that lets anyone run local AI without cloud dependencies or subscriptions.*
